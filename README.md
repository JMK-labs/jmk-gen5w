## JMK 런처 메뉴 (jmk-map-menu)

MAP 버튼을 1.5초 누르면 화면 위에 메뉴가 뜹니다. 다시 1.5초 누르거나, 바깥이나 ✕를 누르면 닫힙니다.

- **Wi-Fi Driver**: 차 핫스팟 상태·켜고 끄기, 폰 핫스팟 접속, 저장된 네트워크, 주변 네트워크 찾기
- **Active Ambient**: 음악 재생 중 / 음악 멈춤 / 통화 중별 조명 효과와 세부 설정
- **HUD · 계기판**: Wireless AutoPlay 길안내 설정
- **차박 모드**: 5초 뒤 화면·조명을 끄고, 박수 두 번이면 음성 인식을 켭니다
- **커스텀 워머창** (처음에는 꺼짐): WARMER 버튼을 누르면 순정 팝업 대신 화면 아래에 워머창이 뜹니다. 안드로이드 오토·카플레이 화면은 그대로입니다. 핸들 열선, 운전석·조수석 열선/통풍, 뒷좌석 열선(있는 차만). 켜 두는 동안 카플레이 중 블루링크 통화 팝업은 카플레이 화면 위에 겹쳐 뜹니다
- **동의 화면 눈으로 확인**: 시동 때 안전 안내 화면을 눈으로 확인할 시간을 준 뒤 넘깁니다 (2.3.29부터 이 이름, 예전 이름 동의 화면 패스)
- **버튼 매핑**: 메뉴를 여는 버튼 바꾸기 (MAP · NAV · MEDIA는 1.5초, 콘솔 ☆ · 핸들 ☆는 한 번 누르기 · 순정 바로가기 대체)
- **USB 포트**: Phone(USB 메모리·유선 AA·동글) / PC ADB 전환
- **NEMESIS** 매니저 열기, **재부팅**
- **⚙ 설정**: 업데이트(설치된 버전, 업데이트 받기, 설치·제거, 차량 코드)와 실험실

**실험실** (⚙ 설정 → 실험실, 입장이 허가된 분만 이용할 수 있습니다): 차박 +(차박 때 앞좌석을 앞으로), 조수석 이지억세스, 커스텀 워머창 +(조수석 시트 버튼·버튼 순서·위치·크기), Active Ambient +(여러 조명 모드), HUD · 계기판 +, 미디어 팝업(재생 중인 곡을 작은 팝업으로), 바로가기. 시트가 움직이는 기능은 차가 멈춰 있을 때만 동작합니다.

## Active Ambient (jmk-ambient-sound)

재생 중인 음악을 분석해 실내 무드등 색과 밝기를 바꿉니다. 블루투스·USB·안드로이드 오토·애플 카플레이 음악 모두 됩니다. 통화 중 조명도 정할 수 있습니다. 설정은 런처 메뉴 → Active Ambient에서 합니다. 런처 메뉴가 먼저 설치되어 있어야 합니다.

## Wi-Fi Driver (jmk-wifi)

순정 Wi-Fi가 없는 국내형 차량에 USB 동글을 꽂아, 헤드유닛이 순정 Wi-Fi 모듈이 있는 것처럼 동작하게 합니다.

- 차 핫스팟이 순정 그대로 동작해서, 순정 Wi-Fi를 쓰는 무선 안드로이드 오토·카플레이 프로그램을 수정 없이 쓸 수 있습니다.
- 동시에 저장된 폰 핫스팟에 자동으로 붙어 헤드유닛에 인터넷을 줍니다(업데이트 확인용). 무선 안드로이드 오토·카플레이를 쓰는 동안에는 끊김을 막으려고 폰 핫스팟을 찾지 않습니다(주변 찾기를 누르면 찾습니다).
- 호환성 모드: 차 핫스팟을 끄고 순정 방식으로 폰 핫스팟에 붙습니다. 네메시스 스토어 등 모든 앱이 인터넷을 씁니다. 그동안 무선 안드로이드 오토·카플레이는 안 되고, 재부팅하면 기본으로 돌아옵니다.
- **폰 핫스팟은 5GHz로 켜 주세요.** 동글은 차 핫스팟과 같은 채널을 씁니다. 그래서 2.4GHz 폰 핫스팟에 붙으면 차 핫스팟도 2.4GHz로 바뀌고, 5GHz가 필요한 무선 안드로이드 오토가 "휴대폰으로부터 응답이 없습니다"로 끊깁니다. 1.4.16부터는 2.4GHz 폰 핫스팟에 붙지 않고, Wi-Fi Driver 화면에 "폰 핫스팟이 2.4GHz"를 띄웁니다(갤럭시: 설정 → 연결 → 모바일 핫스팟 및 테더링 → 모바일 핫스팟 → 대역). 순정 Wi-Fi 모듈이 있는 차의 호환성 모드는 그대로입니다.
- 아이폰은 무선 카플레이를 쓰는 동안 자기 핫스팟을 함께 켤 수 없습니다. 폰 핫스팟은 다른 폰의 것을 쓰세요.
- 처음 설정: 설치하고 재부팅한 뒤 런처 메뉴 → Wi-Fi Driver → 주변 찾기에서 폰 핫스팟을 고르고 비밀번호를 넣습니다.
- AX900급 동글(RTL8851BU, 시험 지원): 동글을 꽂은 채로 헤드유닛을 켜면 자동으로 잡습니다(처음에 CD로 보이는 동글도 자동 전환). 켠 뒤에 꽂았으면 재부팅하세요. 이 드라이버를 올린 뒤 3분 안에 헤드유닛이 다시 시작되는 일이 두 번 이어지면 자동으로 꺼집니다.
- 순정 Wi-Fi 모듈이 있는 차는 설치할 때 자동으로 알아보고 폰 핫스팟 접속 전용으로 설치됩니다(1.4.5부터, 순정 Wi-Fi를 미리 켤 필요 없음). Wi-Fi Driver 화면에서 기본(동글) 또는 호환성 모드(순정 Wi-Fi)를 고릅니다. 1.4.4 이하를 순정 Wi-Fi가 꺼진 채 설치했다면 Wi-Fi Driver를 제거하고 재부팅한 뒤 다시 설치하세요.
- 런처 메뉴가 먼저 설치되어 있어야 합니다. 다른 USB Wi-Fi 패키지가 있으면 먼저 제거하세요.
- 제거하면 바꾼 시스템 파일을 원래대로 되돌립니다(재부팅하면 끝납니다).

## Wireless AutoPlay · HUD · 계기판 길안내

- **Wireless AutoPlay**: 순정 핫스팟으로 무선 카플레이·안드로이드 오토를 씁니다(순정 Wi-Fi 모듈 또는 Wi-Fi Driver 동글).
- **HUD · 계기판 길안내**: 폰 지도 앱의 길안내를 계기판과 HUD에 보여 줍니다. 무선 카플레이에도 필요합니다.
- 둘은 한 쌍으로 설치·업데이트·제거됩니다(런처 메뉴 → ⚙ 설정 → 업데이트). 설치 후 재부팅하면 적용됩니다.
- Leafia · 단풍 · HMG-API 등 다른 무선 프로젝션과는 함께 쓸 수 없습니다. 쓰고 있다면 먼저 제거하고 재부팅하세요(HMG-API를 지운 뒤 AX900mini 동글로 무선 연결이 된 오너 확인이 있습니다).
- 지도 앱 팁: TMAP은 앱 설정에서 "카플레이 HUD 연동"을 켜야 계기판·HUD에 길안내가 나옵니다. NAVER 지도는 차로 표시가 다른 앱과 다르게 나올 수 있습니다.

- **확인 중**: 같은 코드라 될 것으로 보지만 아직 차에서 확인된 기록이 없습니다.
- 표에 없는 차종은 **포팅용 파일 보내기**로 그 차의 파일을 보내 주시면 지원을 준비합니다.

## 설치·제거

**USB 메모리로 한 번에 설치 (권장)**
1. [JMK-Gen5W-USB.zip](https://gen5w.jmkim.dev/download/JMK-Gen5W-USB.zip)을 받아 USB 메모리 맨 위에 압축을 풉니다(`NEMESIS.sh`와 `packages` 폴더가 맨 위).
2. 시동을 켜고 USB를 꽂은 뒤 NEMESIS 창에서 `NEMESIS.sh`를 실행합니다.
3. 런처 메뉴 → 앰비언트 → Wi-Fi Driver → Wireless AutoPlay(+ HUD · 계기판 길안내) 순서로 설치(이미 있으면 업데이트)되고 헤드유닛이 다시 시작합니다. 결과는 USB의 `JMK-INSTALL-LOG.txt`에 남습니다.
4. USB를 빼고 동글을 꽂습니다.

- 함께 쓸 수 없는 앱이 있으면 그 프로그램만 건너뜁니다: 다른 Wi-Fi 앱이 있으면 Wi-Fi Driver, 다른 무선 프로젝션이 있으면 Wireless AutoPlay. 이유는 `JMK-INSTALL-LOG.txt`에 남습니다.
- Korea Projection이 있으면 런처 메뉴와 앰비언트만 설치합니다(Wi-Fi Driver·Wireless AutoPlay는 Korea Projection을 먼저 제거해야 설치됩니다). 런처 메뉴 ⚙ 설정 → 업데이트에서도 "먼저 제거 필요"를 누르면 무엇을 지울지 알려 줍니다.
- 제거: 런처 메뉴 → ⚙ 설정에서 제거하거나 `nemesis uninstall <패키지 이름>`. 문제가 생기면 제거하고 재부팅하면 원래 상태로 돌아갑니다.
- adb로 하나씩 설치: `nemesis install <zip>` (업데이트는 `nemesis install --update <zip>`)

## 업데이트

헤드유닛이 폰 핫스팟으로 인터넷에 연결되면 새 버전을 스스로 확인합니다(설정 화면의 ⟳는 차 통신 모뎀으로도 확인합니다). 새 버전이 있으면 런처 메뉴의 ⚙ 설정에 빨간 숫자가 붙고, 설정 화면에서 **받기**를 두 번 누르면 설치됩니다. 자동으로 설치하지는 않습니다.

- **받기는 폰 핫스팟(또는 테더링)에 연결됐을 때만 됩니다(런처 메뉴 2.3.42부터).** 패키지 파일과 연결 기록 · 포팅 파일은 차 통신 모뎀으로 주고받지 않습니다. 폰이 없으면 "폰 핫스팟에 연결한 뒤 받아 주세요"가 뜹니다.

- **각 버전은 빌드 후 6개월 동안 쓸 수 있습니다.** 기간이 지나면 "업데이트가 필요합니다."가 뜨고 앰비언트 조명과 차박 모드가 멈춥니다. 업데이트 받기는 계속 되니 설정 화면에서 최신 버전을 받으세요(USB로 다시 설치해도 됩니다).
- 업데이트는 개발자 키로 서명되어 있고, 파일 하나라도 맞지 않으면 설치하지 않습니다.
- 인터넷에 연결되지 않는 차는 가끔 USB 설치 파일로 업데이트해 주세요.

**보내는 정보:** 업데이트를 확인할 때 차량 코드(헤드유닛 일련번호의 해시, 8자), 설치된 버전, 헤드유닛 펌웨어·차종 코드, Wi-Fi 종류(동글이면 동글 모델), Wireless AutoPlay 상태(켜짐 · 잠김 이유)를 개발자 서버에 보냅니다. 오류가 나거나 기능이 제대로 동작하지 않으면 그 내용(오류 메시지, 실패한 명령과 결과, 버전, 미디어 팝업 앨범아트 확인용 곡 제목·가수)도 보냅니다. 확인되지 않은 차종은 처음 한 번 헤드유닛 기기 정보도 보냅니다(같은 차종이면 모두 같은 값). HUD · 계기판에서 포팅용 파일 보내기를 누르면 순정 앱 파일을, 제보 보내기를 누르면 길안내 기록과 무선 카플레이 · 안드로이드 오토 연결 기록(정해 둔 순정 프로그램의 기록만, 폰 이름 · 전화번호 · 연락처 · Wi-Fi 이름 · 주소는 지우고)을 보냅니다. Active Ambient는 처음 한 번(설정이 바뀌면 다시) 차의 조명 설정 값과 조명 명령이 적용된 비율을 보냅니다. 통화 상대, Wi-Fi 이름·비밀번호, 위치는 보내지 않고 MAC·IP 주소는 지우고 보냅니다. 오류 보고는 ⚙ 설정의 "오류 보고"로 끌 수 있습니다.

**연결 기록 (런처 메뉴 2.3.39부터):** 오류 보고가 켜져 있으면 무선 카플레이 · 안드로이드 오토와 차 핫스팟이 왜 안 되는지 보기 위한 연결 기록을 개발자 서버로 보냅니다. ① ⚙ 설정의 기록 보내기를 눌렀을 때(하루 5번까지), ② 연결이 실패한 순간 자동으로(순정 "휴대폰 응답 없음", 안드로이드 오토 끊김, 차 핫스팟에 폰이 붙었는데 90초 동안 연결되지 않을 때, Wi-Fi 드라이버 고장, 앰비언트 조명을 되돌리지 못했을 때, 프로그램이 멈췄을 때 · 합쳐서 하루 4번), ③ 개발자가 이 차의 차량 코드로 요청했을 때(보낸 뒤 메뉴에서 한 번 알려 드립니다). 기록에는 순정 프로젝션 · 블루투스 · 핫스팟 로그 중 연결에 관한 줄, Wi-Fi · 핫스팟 상태, JMK 프로그램 상태와 로그, 펌웨어 · 차종 코드 · 버전 · 차량 코드가 들어갑니다. 전화번호, 연락처, 통화 목록, 문자, 노래 정보, 위치, Wi-Fi 이름과 비밀번호, 폰 이름, MAC · IP 주소는 차에서 지운 뒤 보냅니다. 폰 핫스팟(또는 테더링)으로 인터넷이 될 때만 보내고 차 모뎀으로는 보내지 않습니다. 서버는 기록을 공개하지 않고 90일 뒤 지웁니다. 오류 보고를 끄면 담지도 보내지도 않고, 남은 기록도 지웁니다.
